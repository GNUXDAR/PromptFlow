# PromptFlow

> यह [मूल स्पेनिश दस्तावेज़](../../../README.md) का अनुवाद है। यदि दोनों में अंतर हो, तो मूल दस्तावेज़ मान्य होगा।

Linux और Android के लिए टेलीप्रॉम्प्टर: स्क्रीन की रिफ़्रेश दर पर स्मूद स्क्रॉल, क्षैतिज/ऊर्ध्वाधर मिरर, स्क्रिप्ट में पॉज़ और क्यू, LAN (WebSocket) पर रिमोट कंट्रोल, ब्लूटूथ पैडल और लोकल वॉइस ट्रैकिंग (Vosk)।

```bash
flutter pub get
flutter run -d linux          # प्रॉम्प्टर + कंट्रोल सर्वर
flutter run -d <android-id>   # प्रॉम्प्टर या रिमोट कंट्रोल
flutter test                  # इंजन, पार्सर, प्रोटोकॉल (असली सॉकेट) और वॉइस
```

### वॉइस ट्रैकिंग (वैकल्पिक, ऑफ़लाइन)

लोकल स्पीच रिकग्निशन [Vosk](https://alphacephei.com/vosk/) की मदद से टेक्स्ट आपकी आवाज़ की गति के साथ आगे बढ़ता है। 11 भाषाओं के मॉडल उपलब्ध हैं: es, en, pt, fr, de, it, ru, zh, ja, ko और hi।

- **Android:** कोई स्क्रिप्ट खोलें और **सेटिंग्स → आवाज़** पर जाएँ। भाषा चुनें, *मॉडल डाउनलोड करें* दबाएँ और फिर HUD का माइक्रोफ़ोन दबाएँ। पहली बार ऐप माइक्रोफ़ोन की अनुमति माँगता है।
- **Linux:** इंजन को एक बार इंस्टॉल करें और मॉडल ऐप से या स्क्रिप्ट से डाउनलोड करें:
  ```bash
  tool/setup_vosk_linux.sh      # libvosk + स्पेनिश मॉडल
  flutter run -d linux
  ```
  PulseAudio/PipeWire का डिफ़ॉल्ट माइक्रोफ़ोन इस्तेमाल होता है।

* आर्किटेक्चर और टेक स्टैक चुनने का औचित्य: [`docs/ARCHITECTURE.md`](../en/ARCHITECTURE.md)
* WebSocket/UDP प्रोटोकॉल: [`docs/PROTOCOL.md`](../en/PROTOCOL.md)
* स्क्रॉल इंजन: [`lib/engine/scroll_engine.dart`](../../../lib/engine/scroll_engine.dart) + [`lib/engine/prompter_painter.dart`](../../../lib/engine/prompter_painter.dart)

## शॉर्टकट (कीबोर्ड और पैडल)

| कुंजी | क्रिया |
|---|---|
| Space / Enter / Play-Pause | चलाएँ / रोकें |
| Page Up / ← | 5 सेकंड पीछे |
| Page Down / → | 5 सेकंड आगे |
| ↑ / ↓ | ±10 WPM |
| H / V | क्षैतिज / ऊर्ध्वाधर मिरर |
| + / − | फ़ॉन्ट का आकार |
| Home | शुरुआत पर लौटें |
| S | सेटिंग्स |
| Esc | बाहर निकलें |

टचस्क्रीन जेस्चर: चलाने या रोकने के लिए डबल टैप, स्क्रिप्ट में स्क्रॉल करने के लिए ऊपर-नीचे ड्रैग, और HUD दिखाने के लिए सिंगल टैप।

## योगदान करें

योगदान का स्वागत है! कोड, असली हार्डवेयर पर टेस्ट, दस्तावेज़, अनुवाद या विचार: हर योगदान मायने रखता है।

**पहले [योगदान गाइड](CONTRIBUTING.md) पढ़ें।** मुख्य बातें:

1. `develop` से `tipo/descripcion` फ़ॉर्मैट (`feat/…`, `fix/…`, `docs/…`, `i18n/…`) में नई ब्रांच बनाएँ।
2. pull request **`develop` के विरुद्ध** खोलें। `main` में केवल प्रकाशित संस्करण आते हैं।
3. भेजने से पहले: `flutter analyze` बिना किसी चेतावनी के और `flutter test` पूरी तरह सफल।

### कहाँ से शुरू करें

- **वॉइस ट्रैकिंग को बेहतर बनाना**: अलग-अलग भाषाओं की असली रिकॉर्डिंग के साथ (गेन, डेड ज़ोन, अलाइनर विंडो)।
- **अरबी वॉइस मॉडल** जो मोबाइल के लिए उपयुक्त हो, अगर कोई छोटा मॉडल आए।
- **`follower` भूमिका**: एक दूसरा डिवाइस जो मुख्य प्रॉम्प्टर के साथ चलते हुए स्क्रिप्ट दिखाए।
- **पढ़ते समय स्क्रीन हमेशा चालू** (`wakelock_plus`)।
- **पैकेजिंग**: Linux के लिए Flatpak या AppImage, और Android बिल्ड।
- **असली डिवाइसों पर टेस्ट**: ब्लूटूथ पैडल, टैबलेट, Raspberry Pi (ARM64) और क्लाइंट आइसोलेशन वाले Wi‑Fi नेटवर्क।

कोई bug मिला या कोई विचार है? एक [issue](https://github.com/GNUXDAR/PromptFlow/issues/new/choose) खोलें।
