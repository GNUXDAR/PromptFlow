# PromptFlow

> هذه الوثيقة مترجمة عن [الأصل الإسباني](../../../README.md). في حال وجود اختلاف بينهما، يُعتمد الأصل.

جهاز تلقين (Teleprompter) لنظامَي Linux وAndroid: تمرير سلس بمعدل تحديث الشاشة، وانعكاس أفقي/عمودي، وتوقفات وإشارات (cues) داخل النص، وتحكم عن بُعد عبر الشبكة المحلية (WebSocket)، ودواسات Bluetooth، وتتبع صوتي محلي (Vosk).

```bash
flutter pub get
flutter run -d linux          # المُلقّن + خادم التحكم
flutter run -d <android-id>   # المُلقّن أو جهاز التحكم عن بُعد
flutter test                  # المحرك والمحلل والبروتوكول (مقابس حقيقية) والصوت
```

### التتبع الصوتي (اختياري، دون اتصال)

يتقدم النص بإيقاع صوتك بفضل [Vosk](https://alphacephei.com/vosk/)، وهو نظام محلي للتعرف على الكلام. تتوفر نماذج لـ 11 لغة: es وen وpt وfr وde وit وru وzh وja وko وhi.

- **Android:** افتح نصًا وانتقل إلى **الإعدادات ← الصوت**. اختر اللغة، واضغط *تنزيل النموذج*، ثم اضغط الميكروفون في الـ HUD. في المرة الأولى يطلب التطبيق إذن استخدام الميكروفون.
- **Linux:** ثبّت المحرك مرة واحدة، ثم نزّل النموذج من التطبيق أو باستخدام السكربت:
  ```bash
  tool/setup_vosk_linux.sh      # libvosk + النموذج الإسباني
  flutter run -d linux
  ```
  يُستخدم الميكروفون الافتراضي في PulseAudio/PipeWire.

* البنية المعمارية ومبررات اختيار التقنيات: [`docs/ARCHITECTURE.md`](../en/ARCHITECTURE.md)
* بروتوكول WebSocket/UDP: [`docs/PROTOCOL.md`](../en/PROTOCOL.md)
* محرك التمرير: [`lib/engine/scroll_engine.dart`](../../../lib/engine/scroll_engine.dart) + [`lib/engine/prompter_painter.dart`](../../../lib/engine/prompter_painter.dart)

## الاختصارات (لوحة المفاتيح والدواسة)

| المفتاح | الإجراء |
|---|---|
| Space / Enter / Play-Pause | تشغيل / إيقاف مؤقت |
| Page Up / ← | الرجوع 5 ثوانٍ |
| Page Down / → | التقدم 5 ثوانٍ |
| ↑ / ↓ | ±10 WPM |
| H / V | انعكاس أفقي / عمودي |
| + / − | حجم الخط |
| Home | العودة إلى البداية |
| S | الإعدادات |
| Esc | الخروج |

إيماءات الشاشة اللمسية: نقرة مزدوجة للتشغيل أو الإيقاف المؤقت، والسحب العمودي للتنقل في النص، ونقرة واحدة لإظهار الـ HUD.

## المساهمة

المساهمات مرحَّب بها! الكود، أو الاختبار على أجهزة حقيقية، أو التوثيق، أو الترجمات، أو الأفكار: كل شيء يُحدث فرقًا.

**اقرأ أولًا [دليل المساهمة](CONTRIBUTING.md).** الأساسيات:

1. أنشئ فرعًا جديدًا من `develop` بالصيغة `tipo/descripcion` (`feat/…`، `fix/…`، `docs/…`، `i18n/…`).
2. افتح طلب الدمج (pull request) **مقابل `develop`**. لا يستقبل `main` إلا الإصدارات المنشورة.
3. قبل الإرسال: `flutter analyze` دون أي تحذيرات، و`flutter test` ناجح بالكامل.

### من أين تبدأ

- **ضبط التتبع الصوتي** باستخدام تسجيلات حقيقية بلغات مختلفة (الكسب، والمنطقة الميتة، ونافذة المُحاذي).
- **نموذج صوتي للعربية** مناسب للهاتف المحمول، إن ظهر نموذج صغير.
- **دور `follower`**: جهاز ثانٍ يعرض النص متابعًا المُلقّن الرئيسي.
- **إبقاء الشاشة مضاءة دائمًا** أثناء القراءة (`wakelock_plus`).
- **التحزيم**: Flatpak أو AppImage لنظام Linux، وبُنى Android.
- **الاختبار على أجهزة حقيقية**: دواسات Bluetooth، والأجهزة اللوحية، وRaspberry Pi (ARM64)، وشبكات Wi‑Fi التي تفعّل عزل العملاء.

هل وجدت خطأً أو لديك فكرة؟ افتح [issue](https://github.com/GNUXDAR/PromptFlow/issues/new/choose).
