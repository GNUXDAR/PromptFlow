# PromptFlow

> Перевод с испанского оригинала. В случае расхождений приоритет имеет [оригинал](../../../README.md).

Телесуфлёр для Linux и Android: плавная прокрутка с частотой обновления экрана, зеркалирование по горизонтали и вертикали, паузы и метки (cues) в сценарии, удалённое управление по локальной сети (WebSocket), Bluetooth-педали и локальное отслеживание голоса (Vosk).

```bash
flutter pub get
flutter run -d linux          # суфлёр + сервер управления
flutter run -d <android-id>   # суфлёр или пульт ДУ
flutter test                  # движок, парсер, протокол (реальные сокеты) и голос
```

### Отслеживание голоса (необязательно, без интернета)

Текст движется в темпе вашей речи благодаря [Vosk](https://alphacephei.com/vosk/) — локальному распознаванию речи. Есть модели для 11 языков: es, en, pt, fr, de, it, ru, zh, ja, ko и hi.

- **Android:** откройте сценарий и перейдите в **Настройки → Голос**. Выберите язык, нажмите *Скачать модель*, а затем значок микрофона в HUD. При первом запуске приложение запросит доступ к микрофону.
- **Linux:** один раз установите движок и скачайте модель из приложения или скриптом:
  ```bash
  tool/setup_vosk_linux.sh      # libvosk + испанская модель
  flutter run -d linux
  ```
  Используется микрофон по умолчанию в PulseAudio/PipeWire.

* Архитектура и обоснование выбора стека: [`docs/ARCHITECTURE.md`](../en/ARCHITECTURE.md)
* Протокол WebSocket/UDP: [`docs/PROTOCOL.md`](../en/PROTOCOL.md)
* Движок прокрутки: [`lib/engine/scroll_engine.dart`](../../../lib/engine/scroll_engine.dart) + [`lib/engine/prompter_painter.dart`](../../../lib/engine/prompter_painter.dart)

## Горячие клавиши (клавиатура и педаль)

| Клавиша | Действие |
|---|---|
| Пробел / Enter / Play-Pause | Воспроизведение / пауза |
| Page Up / ← | Назад на 5 с |
| Page Down / → | Вперёд на 5 с |
| ↑ / ↓ | ±10 WPM |
| H / V | Зеркалирование по горизонтали / вертикали |
| + / − | Размер шрифта |
| Home | В начало |
| S | Настройки |
| Esc | Выход |

Жесты на сенсорном экране: двойное касание — воспроизведение или пауза, вертикальное перетаскивание — прокрутка сценария, одиночное касание — показать HUD.

## Как помочь проекту

Мы рады любому вкладу! Код, тестирование на реальном оборудовании, документация, переводы или идеи — всё пригодится.

**Сначала прочитайте [руководство для контрибьюторов](CONTRIBUTING.md).** Главное:

1. Создайте новую ветку от `develop` в формате `тип/описание` (`feat/…`, `fix/…`, `docs/…`, `i18n/…`).
2. Открывайте pull request **в `develop`**. В `main` попадают только опубликованные версии.
3. Перед отправкой: `flutter analyze` без предупреждений и `flutter test` проходит полностью.

### С чего начать

- **Тонкая настройка отслеживания голоса** на реальных записях на разных языках (усиление, мёртвая зона, окно выравнивателя).
- **Голосовая модель для арабского языка**, пригодная для мобильных устройств, если появится компактная.
- **Роль `follower`**: второе устройство, которое показывает сценарий синхронно с основным суфлёром.
- **Экран не гаснет** во время чтения (`wakelock_plus`).
- **Пакетирование**: Flatpak или AppImage для Linux и сборки для Android.
- **Тестирование на реальных устройствах**: Bluetooth-педали, планшеты, Raspberry Pi (ARM64) и сети Wi‑Fi с изоляцией клиентов.

Нашли баг или есть идея? Откройте [issue](https://github.com/GNUXDAR/PromptFlow/issues/new/choose).
